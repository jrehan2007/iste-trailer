## Pull the latest names & photos from the live website (recommended before the event)
1. Create a file `.env.local` in this folder with one line:
   SUPABASE_ANON_KEY=<same value as VITE_SUPABASE_ANON_KEY in your Vercel project settings>
2. Run `npm run sync` (it also runs automatically before `npm run dev`).
   It downloads the current tenure's team from the website, saves every photo locally, and the trailer uses it.
   Without the key, the built-in roster is used.
